# API利用設計（モデル・コスト）

前提: LLM呼び出しは全て OrcaRouter（OpenAI互換ルーター、`baseURL: https://api.orcarouter.ai/v1`）経由。
料金は **OrcaRouterが接続先モデルのOpenAI公式価格に準拠している前提**で試算（OrcaRouter独自の上乗せ有無は未確認）。

## 1. 現在利用中のモデルと切り替え方法

| 用途 | 呼び出し箇所 | 環境変数 | 現在値 | Web Search |
|---|---|---|---|---|
| ヒアリング質問生成 | `/api/interview` | `ORCAROUTER_MODEL` | `openai/gpt-4o-mini` | なし |
| 基礎調査（Pass1） | `/api/research` 内 | `ORCAROUTER_FACT_MODEL` | `openai/gpt-4o-mini-search-preview` | あり |
| 詳細生成（Pass2） | `/api/research` 内 | `ORCAROUTER_MODEL` | `openai/gpt-4o-mini` | なし（search系モデルの出力上限〈実測1,000〜1,500トークン〉回避のため意図的に無効） |

**切り替え方法**: Vercel Environment Variables の `ORCAROUTER_MODEL` / `ORCAROUTER_FACT_MODEL` を書き換えて再デプロイするだけ（コード変更不要、`lib/OrcaRouterClient.ts` が実行時に読む）。`ORCAROUTER_FACT_MODEL` を空にするとPass1自体をスキップする。

## 2. 現状の1回あたり利用料金（実測ベース）

「いちご農園を始めたい」テーマで実際にAPIを呼び出し、トークン数を実測（2026-08-14）。

| 呼び出し | モデル | input | output | 料金 |
|---|---|---|---|---|
| ヒアリング生成 | gpt-4o-mini | 1,568 | 248 | $0.0004 |
| 基礎調査（トークン分） | gpt-4o-mini-search-preview | 961 | 763 | $0.0006 |
| 基礎調査（Web Search呼び出し、$25/1,000回） | — | — | — | $0.0250 |
| 詳細生成（8,226中7,040がキャッシュ） | gpt-4o-mini | 8,226 | 5,292 | $0.0039 |
| **1回のリサーチ実行合計** | | | | **約 $0.030（≒4.5円 @150円/$）** |

→ **Web Search呼び出し課金が全体の8割強**を占める支配的コスト要因。トークン代自体はごく小さい。

## 3. バランス型改良案の試算（上位モデル化 + Pass2もWeb Search対応）

※ このセクションの「上位モデル」は `gpt-4o` 系。後述の4章の通り、OrcaRouterには実際にはさらに上位のモデル層があるため、**これは「最高性能」ではなく費用とのバランスを取った中位グレードの改良案**として位置づける。

想定構成: ヒアリングは `gpt-4o`、基礎調査＋詳細生成は `gpt-4o-search-preview` に統合し1回のWeb Search付き呼び出しで完結させる（現行の2パス構成を解消）。
入力 約9,000トークン、出力 約7,500トークン（現行Pass1+Pass2合計6,055トークンより厚め。根拠の多い出力になる想定）。

**Web Search回数は当初2回で試算していたが少なすぎた。** `prompts/research_system.md` の改修（2026-08-13）で「今のまま」＋3道それぞれについて、素朴なルートだけでなく第三者承継・借地・補助金といった代替ルートの実在裏付けまで探しに行く方針にしたため、トピックごとに複数回検索する前提で見直す。

| シナリオ | Web Search回数 | 想定根拠 | 料金（トークン分$0.0975込み） |
|---|---|---|---|
| 少なめ | 3回 | 今のまま＋3道をまとめて数回で検索 | $0.1725 |
| **想定（採用）** | **6回** | 今のまま1回 ＋ 3道×（相場・代替ルートの裏付け）各1〜2回 | **$0.2475** |
| 多め | 10回 | 各道で相場・制度・リスクを個別に検索 | $0.3475 |

| 呼び出し | モデル | 料金 |
|---|---|---|
| ヒアリング生成 | gpt-4o | $0.0064 |
| 統合リサーチ（想定シナリオ、Web Search 6回込み） | gpt-4o-search-preview | $0.2475 |
| **1回のリサーチ実行合計** | | **約 $0.25（≒38円 @150円/$）** ／ 少なめ〜多めのレンジで $0.18〜$0.35 |

→ 現状（約$0.030）比で**約8.5倍**（レンジで約6〜12倍）。月100回の利用でも $25（≒3,750円）程度に収まる規模感。

**注意**: 現行構成でPass2にsearch系モデルを使わない理由は「出力トークンが1,000〜1,500程度で打ち切られる」という実測不具合（`gpt-4o-mini-search-preview`）。フルサイズの `gpt-4o-search-preview` で同じ制約が解消するかは未検証のため、本格導入前に実機検証が必要。また実際のWeb Search回数はモデルの生成内容次第で変動するため、上表はあくまで設計上の見積もり。

## 4. 真の最高性能構成の試算（OrcaRouterの最上位モデル）

`GET /v1/models`（OrcaRouter）を実際に叩いたところ、`gpt-4o` 系より大幅に上位のモデル層が存在することを確認した。3章の案は**最高性能ではなく中位グレード**だった。

### OrcaRouterで確認した実際の価格（2026-08-14実測、$/1Mトークン）

| モデル | prompt | completion | 備考 |
|---|---|---|---|
| gpt-4o-search-preview（3章の案） | $2.5 | $10 | 参考: 中位グレード |
| gpt-5-search-api | $1.25 | $10 | 検索ネイティブ、比較的安価 |
| claude-opus-5 | $5 | $25 | 上位クラスの中では割安 |
| gpt-5-pro | $15 | $120 | |
| gpt-5.2-pro | $21 | $168 | |
| **gpt-5.5-pro** | **$30** | **$180** | カタログ内で最高額（採用） |
| gpt-5.4-pro | $60 | $270 | 単価最高額。長コンテキスト(1M)重視用途向け |

### 想定構成

- **Pass1（グラウンディング）**: `gpt-5-search-api` で事実収集（現行のPass1と同役割、検索ネイティブで比較的安価）
- **Pass2（統合生成）**: `gpt-5.5-pro` で深い推論・執筆（Web Searchは付けず、Pass1の事実を渡して合成に専念させることで、高額な推論モデルに検索課金を重ねない設計）

### 試算（暫定・実測検証中）

現行と同じプロンプト量（入力 約8,200トークン、出力 約5,300トークン）と仮定した場合：

| 呼び出し | モデル | 料金 |
|---|---|---|
| ヒアリング生成 | gpt-5.1（$1.25/$10） | 約$0.005 |
| Pass1グラウンディング | gpt-5-search-api | 約$0.01（+ 検索ツール課金は未確認） |
| **Pass2統合生成** | **gpt-5.5-pro** | **input $0.25 + output $0.95 ≒ $1.20** |
| **1回のリサーチ実行合計** | | **約 $1.2〜$3.1（≒180〜470円）** |

- 下限$1.2は可視出力トークンのみで計算した値。上限$3.1は、推論系モデルが可視出力の裏で消費する「隠れ思考トークン」も課金対象になるケースを見込んだ値（visible出力の2倍を仮置き）。
- **現状（$0.030）比で約40〜100倍。**
- `gpt-5.5-pro` へ実際に本番プロンプトを投げて実測トークン数を検証中（レスポンスに数分以上を要する推論モデルのため未完了）。確定次第この節を実測値に更新する。

### まとめ（3段階比較）

| 構成 | 1回あたり | 現状比 |
|---|---|---|
| 現状 | 約$0.03（≒4.5円） | 1x |
| バランス型（3章、gpt-4o系） | 約$0.25（≒38円） | 約8.5x |
| 真の最高性能（4章、gpt-5.5-pro系） | 約$1.2〜$3.1（≒180〜470円） | 約40〜100x |
